## Tuần 2 — Auth & RBAC, Frontend skeleton

**Đã đạt:**
- Backend: model `users`, JWT + refresh token, hash password (bcrypt/argon2), `/auth/register`, `/auth/verify`, `/auth/login`, `/auth/refresh` (`2e2f825`)
- Alembic migration đầu tiên cho bảng `users` (`backend/alembic/versions/7cb889724d42_create_users_table.py`)
- RBAC: `require_role()` dependency dùng theo route, chặn tự đăng ký role admin qua API công khai
- Rate limit `slowapi`: 5 lần/phút cho `/auth/login` và `/auth/register`, đọc đúng IP thật sau proxy Render
- CORS middleware đọc `CORS_ORIGINS`
- Test: `backend/tests/test_auth.py` (~150 dòng qua 2 commit `2e2f825`, `67c1434`)
- Frontend: `react-router-dom`, layout/nav theo role, form đăng ký/xác minh/đăng nhập gọi API thật, tự refresh access token (`67c1434`)

**Deliverable kế hoạch:** "Auth + RBAC hoạt động end-to-end (backend enforce, không chỉ ẩn UI), frontend skeleton deploy được" — **đạt**, RBAC enforce ở dependency backend theo đúng ràng buộc `.claude/docs/security.md`.
